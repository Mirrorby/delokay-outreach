# Delokay: первое сообщение в Telegram

Один контакт за короткий запуск GitHub Actions, от личного аккаунта через
Telethon. ИИ, входящих обработчиков, уточнений и повторных предложений нет.
Railway, Cloudflare и постоянно работающий компьютер не нужны.

## Запуск

Рабочий workflow находится в `Mirrorby/instagram-store-finder` → Actions →
**Delokay first message**. Он использует уже сохранённые там секреты и
проверенный коммит кода из этого репозитория. Секреты между репозиториями
не копируются. Оба workflow используют одну группу concurrency со сборщиком.

Режимы: `setup` создаёт только два служебных листа; `check` проверяет таблицу
и авторизацию без сообщений; `test` отправляет текст в ваше «Избранное»;
`enable` включает расписание; `pause` останавливает; `send` выполняет одну
попытку с учётом всех настроек.

В существующей таблице появятся **Рассылка — настройки** и **Рассылка — журнал**.
Текст, пауза, часы и лимит меняются в настройках. Начальное состояние — пауза.
Расписание: каждые полчаса с 11:17 до 17:47 по Минску; интервал не меньше
40 минут означает обычно одну попытку в час. Не более 10 попыток в день.
GitHub может задерживать или пропускать запуск: точное время не гарантируется.
Стандартные Linux runners публичных репозиториев бесплатны по правилам GitHub.

## Какие строки обрабатываются

Скрипт читает Telegram-листы сборщика с колонками `Telegram ID`, `Username`,
`Бот`, `Удалённый аккаунт`, `Статус`, `Дата первого сообщения`.
Берёт только статус `Новый` или пустой и пустую дату первого сообщения.
Чтобы исключить контакт, поставьте `Не подходит` или любой другой статус.
Instagram-лист не обрабатывается. Без username, ботов и удалённые аккаунты
пропускаем. Один Telegram ID в разных группах считается одним контактом.

Проверяется совпадение username с исходным Telegram ID и отсутствие любой
предыдущей переписки. Сначала создаётся запись в журнале, потом перед
отправкой исходная строка помечается `Написал` с датой. Если результат
неизвестен, автоматического повтора нет: проверьте журнал и сам Telegram.
`Написал` в источнике при неудаче поэтому не является подтверждением доставки;
подтверждённая отправка обозначена в журнале как `Отправлено`.

Не сортируйте и не перемещайте строки во время отправки. Не запускайте другую
рассылку или старый Railway sender с тем же аккаунтом/очередью одновременно.
При ограничении Telegram рассылка выключается. Небольшой лимит не гарантирует
отсутствия ограничений со стороны Telegram.

Ни контакты, ни Google-ключ, ни Telegram-сессия не сохраняются в Git,
артефактах или публичных логах. Для самостоятельного запуска требуются секреты:
`TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `TELEGRAM_SESSION`,
`GOOGLE_SERVICE_ACCOUNT_JSON`; `GOOGLE_SHEET_ID` — необязательно.
